# automaktab.uz — Folded Ascent

`Folded Ascent` is the refined logo direction selected from the six-concept exploration. It represents scattered operating signals being folded into one controlled flow that rises toward a clear result.

## Authoritative assets

- `master/icon.svg` — primary flat icon
- `master/icon-mono.svg` — one-colour, background-punched icon
- `master/icon-reverse.svg` — Field Paper icon for Control Ink backgrounds
- `master/lockup-horizontal.svg` — primary `automaktab.uz` lockup
- `master/lockup-horizontal-reverse.svg` — horizontal lockup for Control Ink backgrounds
- `master/lockup-stacked.svg` — stacked lockup
- `master/lockup-stacked-reverse.svg` — stacked lockup for Control Ink backgrounds
- `presentation/lockup-premium.svg` — gradient/shadow presentation treatment only
- `applications/telegram-avatar-paper.svg` — Telegram-ready light avatar
- `applications/telegram-avatar-ink.svg` — Telegram-ready dark avatar

All wordmark letters are outlined SVG paths from the approved Unbounded Bold typeface. The logo does not depend on a font being installed.

## Usage rules

- Use the flat master for the website, product, print and ordinary social assets.
- Use the premium treatment only in controlled brand presentations. It is not the favicon or production master.
- Keep clear space equal to at least one ribbon width around the icon.
- Use the colour icon at `24px` or larger. At `16px`, use the mono icon.
- Never move, duplicate or recolour the single signal point.
- Do not add a car, wheel, road, traffic light, bevel, extra shadow or extra gradient to the master.
- Telegram uploads must use the prepared avatar files; their critical geometry stays inside the circular safe area.

## Reference findings

The blue ribbon/check category is crowded and therefore not automatically distinctive. The final system deliberately avoids treating the reference image as a trace: it uses its own proportions, asymmetrical caps, real fold contrast, a proprietary signal point, an outlined `automaktab.uz` wordmark and the existing brand palette. This is directional screening, not legal trademark clearance.

Before trademark filing, run a professional similarity search in the intended jurisdictions and service classes.
